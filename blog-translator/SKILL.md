  # blog-translator Skill
  
  ## 前置检查
  
  1. **确认依赖**：本 Skill 依赖 `web-access` Skill 提供网络操作能力。开始前确保 `web-access` 已正确配置（Node.js 22+、Chrome remote-debugging 已开启）。
  2. **确认成员列表文件**：检查当前目录是否存在 `Hinatazaka Member List.md` 和 `Sakurazaka Member List.md`。若缺失，提示用户放置文件。
  
  ## 触发条件与解析
  
  - **触发词**：用户输入包含“blog翻译”及成员名（例如：“blog翻译 髙桥未来虹”、“blog翻译 小坂菜绪”等）。
  - **解析流程**：
    1. 从用户输入中提取成员名（支持中文、日文、罗马音等常见写法）。
    2. 分别在两个成员列表文件中查找匹配项。
       - 若仅在日向坂列表匹配 → 目标官网为日向坂46官方博客页面 `https://www.hinatazaka46.com/s/official/diary/member?ima=0000`
       - 若仅在樱坂列表匹配 → 目标官网为樱坂46官方博客页面 `https://sakurazaka46.com/s/s46/diary/blog/list?ima=0000`
       - 若同时匹配或均不匹配 → 提示用户“未找到该成员，请确认成员名是否正确并重试”，结束流程。
    3. 确定成员后，记录其官方姓名（用于后续定位博客）。
  
  ## 获取最新博客内容
  
  **必须使用 `web-access` Skill 的浏览器 CDP 模式**，因为官方博客页面依赖 JavaScript 渲染，且可能包含懒加载图片。
  
  操作步骤（由本 Skill 调用 web-access 执行）：
  
  1. 通过 CDP 创建新 tab，导航至对应团体的博客列表页。
  2. 在列表页中找到该成员的最新一篇博客（通常按发布时间降序排列，第一篇即为最新）。
  3. 点击该博客链接（使用 `/click` 或提取 URL 后用 `/new` 打开），进入详情页。
  4. 等待页面完全加载（包括图片）。
  5. 使用 `/eval` 提取以下内容：
     - 博客标题、发布时间。
     - 正文 HTML 或纯文本（保留段落结构）。
     - 所有图片的 `<img>` 标签的 `src` 属性（或 `data-src` 等真实图片 URL）。
  6. 获取完整页面截图（作为备选，但主要依靠提取的文本和图片 URL）。
  
  > **注意**：若页面要求登录，则按 `web-access` 的登录判断逻辑处理——提示用户在 Chrome 中登录该网站，然后继续。
  
  ## 翻译与输出格式
  
  ### 翻译要求
  - 将博客正文翻译为中文（简体），保持原文语气和分段。
  - 使用 AI 翻译能力（模型内置），确保流畅自然。
  - 输出时**日文在上，中文在下**，逐段对应（若原文有分段，译文也应分段）。
  
  ### 输出格式（严格遵循）
  ```

  

  {成员姓名}｜{博客标题}（{发布日期}）

  {日文段落1}
  {中文段落1}

  {日文段落2}
  {中文段落2}

  ...

  [图1]
  {图片1 URL 或 直接显示图片（若支持Markdown）}
  [图2]
  {图片2 URL}
  ...

  来源：{原文链接} ｜ 日期：{发布日期} ｜ AI译稿，非官方译文，仅供学习交流

  text

  ```
  - **标题**：成员姓名 + ｜ + 博客标题 + （日期），日期格式为 `YYYY.M.D`。
  - **正文**：按原文段落顺序，日文原文段落和中文翻译段落交替出现，每段之间空一行。
  - **图片**：在正文中原本出现图片的位置标记 `[图1]`、`[图2]` ……，并在正文结束后统一列出所有图片（可输出图片 URL 或嵌入 Markdown 图片语法）。
  - **结尾**：固定添加“来源：{原文链接} ｜ 日期：{发布日期} ｜ AI译稿，非官方译文，仅供学习交流”。
  
  **禁止输出**：任何思考过程、提示信息、操作日志等多余文字。只输出上述格式内容。
  
  ## 操作流程示例（内部执行，不输出给用户）
  
  假设用户输入：“blog翻译 髙桥未来虹”
  
  1. 匹配成员 → 日向坂46。
  2. 打开 `https://www.hinatazaka46.com/s/official/diary/member?ima=0000`。
  3. 在列表中查找“髙桥未来虹”的最新文章（可通过 eval 获取所有文章卡片，按日期排序）。
  4. 点击进入详情页。
  5. 提取标题、日期、正文 HTML、图片 URLs。
  6. 翻译正文。
  7. 组装输出内容并打印。
  
  ## 错误处理
  
  - **成员未找到**：输出“未找到该成员，请确认成员名是否正确并重试”。
  - **网络/页面加载失败**：提示“获取博客失败，请检查网络或稍后重试”。
  - **无最新博客**：提示“该成员暂无最新博客”。
  
  ## 与 web-access Skill 的协作
  
  本 Skill 的所有网络操作均委托给 `web-access` Skill，通过其提供的 CDP API 完成。在执行前，确保已加载 `web-access` 并完成前置检查。
  
  ```bash
  # 示例：检查 web-access 依赖
  node "${CLAUDE_SKILL_DIR}/scripts/check-deps.mjs"
  ```

  

  若检查失败，引导用户完成 `web-access` 的配置。
